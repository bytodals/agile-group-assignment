# agile-group-assignment

Collaborative group project built using Agile methodologies.

## Design tokens

We maintain a shared set of design tokens (colors, spacing, radii, typography) used across the frontend app.

- Canonical token source: "AnnaBook/src/styles/tokens.css"
- Frontend global stylesheet: "AnnaBook/styles/globals.css" (imports the tokens and adds base/layout styles)
- Human-readable documentation: "DESIGN.md"
